Prefix, then a command

The same model the app uses: a split tree, a focused pane, and a 1.5-second prefix window.

Click the window, then press Ctrl+A and v.

Built for the keyboard

Everything a terminal day needs, nothing in the way

Panes are separated by a single line. The chrome is a thin top bar and a status line. The rest of the window is your shells.

Your keys stay yours

Outside prefix mode, every key goes straight to the program in the pane, so vim, emacs and tmux behave exactly as they do anywhere else. Press the prefix twice to send it through.

Zoom a pane to fill the window when you need to focus, then drop back into the layout without losing a line of scrollback.

z zoomShift+hjkl swapCtrl+hjkl resize

Every action, one search away

Forgot a binding? Ctrl Shift P opens the command palette: every action with its keys, a new pane in any installed shell, and every color theme. Type a few letters and press Enter.

An Explorer that follows your shell

Press e after the prefix and the Explorer opens on the focused pane's directory. It moves when you cd or switch panes, and updates live as files appear, move or disappear. It even follows Git Bash into /tmp. Inside a git repository it colours changed files, shows the branch and what changed, and o reveals any file in File Explorer.

j/k moveEnter insert pathc cd heree edit

Edit without leaving the terminal

Run splitview edit file.rs, or press e on a file in the Explorer. The editor docks on the right with tabs, syntax colors, line numbers, and find and replace.

When a command changes the file, a clean buffer follows the disk. If you have unsaved edits, SplitView says so and asks before it overwrites anything. Line endings and BOMs are kept, so a one-line change stays a one-line diff.

A scratchpad for every project

Press w after the prefix and jot it down before it's gone: notes, pen strokes, lines, arrows, boxes and circles, in six colors. The select tool moves anything you've drawn.

Each project gets its own pad, picked from the git repository of the focused pane (or its folder), and every change is saved as you go. Open another project and you see its notes, not the last one's.

Enter new notep penv selectCtrlZ undo

Send a dev server to the background

b hides a pane without stopping it. The process keeps running and its output keeps buffering. Shift B lists what's running with each pane's latest line, so you can bring one back or stop it.

Make it look like yours

Settings (, after the prefix) has five palettes to start from, every color, font size and divider thickness, aliases for every shell, a startup banner, and which details the prompt shows.

Let an AI agent drive it, off until you say so

Turn on the MCP server and Claude Code, or any MCP client, can open, read and close panes, run commands and wait for them to finish, and sketch a plan on the scratchpad with you. It listens on this computer only, behind a token, and Settings gives you the one line to add it to Claude Code.

And the rest

Small things that add up

Windows and detached panes

n opens a new window. d pops a pane into its own window, and it goes back when you close it.

Any shell you have

Git Bash, PowerShell, cmd, zsh. Pick a default on first run, or open a pane with any of them using p.

Clickable links

Ctrl+click a URL in any pane to open it in your browser.

Font size on the fly

Ctrl = and Ctrl - resize every pane, and Ctrl 0 resets. JetBrains Mono is bundled.

A config file when you want one

Rebind any key, change the prefix or the prompt style in config.toml, then reload with r.

Quiet when idle

No webview, no blinking, no polling. When nothing changes, SplitView draws nothing and uses next to no CPU.

Claude Code usage at a glance

While Claude Code runs, the status bar shows its context window and your 5-hour and weekly limits. Hover for when they reset.

Wrap long lines

The editor wraps long lines when you want it to. Alt Z toggles it, and it stays the way you left it.

Start with your panels

Settings › Panes chooses whether the Explorer, Editor and Scratchpad are open when a window opens.

SplitView 0.6.0 for Windows

A per-user install: no admin rights, and it replaces a 0.2.x install in place.

Download the installer
SplitView_0.6.0_x64-setup.exe · 5.6 MB · Windows 10 and 11, x64 SHA-256 d4f9c229034c7e487870c1b14102b9dba981eaf3f112ac3f4b23ff601bdcda18

Before you install

  • On first launch SplitView asks which shell to use. Git Bash gives the intended POSIX experience: install Git for Windows if you don't have it. PowerShell and cmd work too.
  • The installer isn't code-signed yet, so SmartScreen will warn you. Check the SHA-256, then choose More info and Run anyway.
  • Your settings live in %APPDATA%\splitview and are kept if you uninstall.
  • macOS and Linux builds aren't published yet.
