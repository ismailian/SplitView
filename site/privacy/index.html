Privacy

Last updated November 27, 2026 · covers SplitView 0.6.0 and this website

SplitView has no accounts, no analytics and no telemetry. The app doesn't send your data to us, and we don't run a server that could receive it.

The app

SplitView doesn't record what you type or what your terminals print. Scrollback is held in memory and goes away when you close the pane.

Each time it starts, SplitView reads splitview.pages.dev/releases/latest.json to see whether a newer version is out. If you choose to update, the installer is downloaded from the project's GitHub releases and checked against the published size and SHA-256 before it runs. These requests carry the app's version but nothing about you or your files.

These are stored on your computer only, in %APPDATA%\splitview on Windows:

  • Settings (settings.json): colors, font size, aliases, banner text, prompt options, your default shell and panel widths.
  • Configuration (config.toml), if you create one.
  • Files you open in the editor, which are read from and saved to your own disk.
  • Scratchpads (scratchpads\): your notes and drawings, one file per project, named after a hash of the project's folder. Delete the folder to remove them.

Programs you run inside SplitView, such as git or npm, make their own network connections. Those are outside SplitView's control.

Claude Code usage

When Claude Code is running on your computer, SplitView shows its usage in the status bar. To do that it reads Claude Code's own files in ~\.claude: the list of running sessions and the end of each session's transcript, for the context size. It doesn't copy or keep them.

For the 5-hour and weekly limits it sends the access token from Claude Code's .credentials.json to Anthropic (api.anthropic.com), the company that issued it, about every two minutes while a session runs. The token goes nowhere else and isn't stored by SplitView. If Claude Code isn't running, none of this happens.

MCP server

The MCP server is off by default. When you turn it on in Settings, SplitView listens on 127.0.0.1 only, so nothing on your network can reach it, and keeps a random access token in its settings file. A program on your computer that presents the token, such as an AI agent you set up, can see your pane titles, working directories and terminal output, type into your panes, and read and change your scratchpads. What the agent then does with that, including sending it to its own provider, is up to that agent and its terms. Turn the server off, or make a new token, to cut access.

This website

This site is hosted on Cloudflare Pages. It sets no cookies and uses no analytics, ads or trackers, and its fonts and scripts are served from this site. Cloudflare processes your request to deliver the pages, which involves technical data such as your IP address and browser details. See Cloudflare's privacy policy.
